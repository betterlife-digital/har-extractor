How to save a HAR file from your browser
  1. Open developer tools (F12, or Cmd+Option+I on a Mac) and choose the Network tab.
  2. Reload the page or repeat the steps that show the problem while the Network tab stays open.
  3. Chrome and Edge: click the download arrow, "Export HAR". Firefox: right-click a request, "Save all as HAR". Safari: "Export" in the Network tab.

HAR files contain cookies, tokens and anything you typed. Use Export, Sanitised HAR before sending one to anyone.

    Filter syntax

    login
    URL, method, status or type contains "login"
    -analytics
    Hide anything containing "analytics"
    status:404 status:5
    Exact status, or any status starting with 5
    method:post
    Request method
    domain:api.example.com
    Host contains this text
    type:js
    fetch, doc, js, css, img, font, media, ws, other
    larger:100k slower:500
    Size above 100 kB, duration above 500 ms
