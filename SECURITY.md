# Security

HAR Extractor runs entirely in your browser and is built so that it cannot make network connections or
run anything contained in a capture. If you find a way it could leak captured data, run code from a HAR
file, or miss a common kind of secret, please report it privately.

## Reporting a vulnerability

Use **Report a vulnerability** on this repository's **Security** tab. Please don't open a public issue
for security problems.

Never attach a real HAR file, because it can contain passwords and session cookies. Describe the problem,
or attach a small made-up example that shows it.

## Supported versions

Fixes go into the latest release. Please check that you are using it before reporting.
